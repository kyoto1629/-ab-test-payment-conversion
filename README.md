# A/B-тест формы оплаты ЖКХ

## Цель эксперимента

Оценить, повышает ли новая форма с упрощённым заполнением реквизитов конверсию в успешную оплату ЖКХ.

- **Группа A:** действующая форма оплаты.
- **Группа B:** новая форма оплаты.
- **Период:** 1–30 апреля 2024 года.
- **Единица рандомизации:** пользователь.
- **Основная метрика:** доля успешных попыток оплаты среди открытий формы.

## Данные и подготовка

Источник — `data/raw/data.xlsx`: таблицы пользователей и попыток оплаты с событиями четырёх этапов воронки.

| Выборка | До очистки | После очистки |
|---|---:|---:|
| Пользователи | 1 504 | 1 503 |
| Попытки оплаты | 2 661 | 2 660 |

При подготовке данных:

- Исключены пользователь без экспериментальной группы и платёж без `user_id`.
- Исправлено одно несоответствие группы: назначение взято из таблицы пользователей.
- Проверены дубликаты идентификаторов и порядок событий воронки — нарушений не обнаружено.
- Сохранены два аномальных значения возраста и один пропуск города: эти признаки не участвуют в расчёте основной метрики. При анализе городов запись с пропуском исключена только из этого среза.

## Методика

Воронка: **открытие формы → ввод реквизитов → подтверждение → успешная оплата**.

Основная конверсия рассчитывается по попыткам платежей. Один пользователь может совершить несколько попыток, поэтому они не считаются независимыми наблюдениями.

Для сравнения групп использован двусторонний z-тест разности конверсий с кластерно-робастной стандартной ошибкой по `user_id`. Расчёт выполнен через пользовательские агрегаты числа попыток и успешных оплат.

- **H₀:** конверсии групп A и B равны.
- **H₁:** конверсии групп различаются.
- **Уровень значимости:** 0,05.

## Результаты

| Показатель | Значение |
|---|---:|
| Конверсия A | 49,81% |
| Конверсия B | 64,40% |
| Абсолютный прирост | +14,59 п.п. |
| Относительный прирост | +29,29% |
| 95% доверительный интервал разности | [10,88; 18,29] п.п. |
| Z-статистика | 7,72 |
| p-value | 1,17 × 10⁻¹⁴ |

Нулевая гипотеза отвергается. Конверсия новой формы статистически значимо выше.

### Переходы воронки

| Переход | A | B | Разница |
|---|---:|---:|---:|
| Открытие → реквизиты | 81,13% | 88,38% | +7,25 п.п. |
| Реквизиты → подтверждение | 71,47% | 80,40% | +8,93 п.п. |
| Подтверждение → оплата | 85,90% | 90,63% | +4,72 п.п. |

Наибольшая наблюдаемая разница между группами — на переходе от ввода реквизитов к подтверждению.

### Сегменты

Конверсия B выше на обоих типах устройств и во всех рассмотренных городах. Наблюдаемый прирост: Android — +14,86 п.п., iOS — +14,12 п.п.; Москва — +18,16 п.п., Санкт-Петербург — +14,24 п.п., регионы — +10,69 п.п.

Сегментный анализ описательный: статистическая значимость различий между сегментами отдельно не проверялась.

## Вывод

Результат поддерживает поэтапное внедрение формы B. При запуске следует контролировать конверсию, технические ошибки, повторные списания и обращения в поддержку.

Финансовый эффект не оценён: отсутствуют данные о суммах платежей, комиссиях, возвратах и технических сбоях. Вывод относится к основной метрике и выборке эксперимента за указанный период.

## Структура проекта

```text
data/raw/          # исходный Excel
data/processed/    # очищенные данные и пользовательские агрегаты
notebooks/         # этапы анализа: качество данных, воронка, тест, сегменты, отчёт
src/ab_test/       # загрузка, очистка, метрики, статистика, графики и отчёт
reports/           # PDF, графики, таблицы и результаты расчётов
tests/             # проверки расчётов и обработки данных
archive/           # исходные материалы
run_analysis.py    # полный запуск анализа
```

## Запуск

Python 3.11+. Из корня проекта в PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe run_analysis.py
```

Отчёт сохраняется в `reports/AB_test_report.pdf`. Таблицы, графики и статистика — в той же папке. Для последовательного просмотра исследования используйте ноутбуки `01`–`05` в `notebooks/`.

Проверка расчётов:

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```
